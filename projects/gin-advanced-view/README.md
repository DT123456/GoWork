# Gin-Advanced Frontend

基于 Vue 3 + Element Plus 的后台管理系统前端

## 功能特性

- 用户登录/注册
- 用户管理
- 角色管理
- 系统日志
- 访问日志
- 文件上传

## 快速开始

```bash
# 安装依赖
npm install

# 开发环境
npm run dev

# 构建生产
npm run build
```

## 项目结构

```
src/
├── api/            # API 接口
├── layout/         # 布局组件
├── router/         # 路由配置
├── stores/         # Pinia 状态管理
├── styles/         # 全局样式
├── utils/          # 工具函数
└── views/          # 页面组件
```
